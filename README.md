# Boundary — Cricket Arcade

A lightweight cricket batting game that runs directly in your web browser. No installation or build step is required.

## Play

Open `index.html` in a modern web browser, then select **Start innings**.

## How to play

- Score at least 24 runs in 2 overs (12 balls) to win.
- Choose a shot: **Ground drive** for a balanced shot, **Lofted hit** for bigger scoring chances with more risk, or **Defend** for a safer, lower-scoring shot.
- Watch the ball travel down the pitch and swing near the marked timing zone.
- Select **Next ball** when you're ready for the next delivery.
- The innings ends when you reach the target, use all 12 balls, or lose 10 wickets.

## Controls

- Click **Hit!** or press **Space** to swing during a delivery. When the ball is not in play, the same controls start the next delivery.
- Select a shot with the on-screen buttons or press **1** for Ground drive, **2** for Lofted hit, and **3** for Defend.
- Click **New game** to reset the innings.
